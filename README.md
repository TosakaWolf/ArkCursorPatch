# 明日方舟鼠标替换补丁

让《明日方舟》PC 版使用 Windows 系统指针，不修改游戏文件。

## 使用

1. 先启动《明日方舟》。
2. 运行 `ArkCursorPatch.exe`，选择“应用系统指针并退出”。
3. 应用成功后工具自动退出，本次游戏会继续使用系统指针。

如果自动定位失败，可在工具中手动设置游戏目录。

需要立即还原时，重新运行工具并选择“恢复当前游戏指针”；重启游戏也会还原。

## 安全

- 工具会请求管理员权限，一次修改当前游戏进程的指针逻辑并重置为 Windows 系统箭头。
- 不修改游戏文件、不注入 DLL；补丁只保留在当前游戏进程中，重启游戏后完全失效。
- 游戏更新后若无法唯一识别目标代码，工具会拒绝修改。

## 声明

> 本工具仅供交流与学习。使用前请自行评估并承担修改游戏进程可能产生的风险。
