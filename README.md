# 明日方舟鼠标替换

让《明日方舟》PC 版停止使用游戏自带鼠标图片，改用 Windows 当前的系统鼠标指针。教程中的点击和拖动提示不受影响。

## 使用

1. 完全退出游戏和鹰角启动器。
2. 运行 `ArkCursorPatch.exe`。
3. 确认主界面显示的游戏目录和状态，然后选择“应用鼠标替换”。
4. 需要还原时选择“恢复原版”。

程序会自动寻找游戏；找不到时可在主界面设置游戏目录。

## 安全与恢复

- 内容版本 `76.0.0` 使用精确校验。其他版本会尝试识别鼠标配置；只有定位结果唯一且结构完整时才允许修改，否则不会写入。
- 应用前会将原文件备份到程序旁边的 `backup` 文件夹。
- 写入后会校验文件，失败时尝试自动恢复。
- 程序不包含完整游戏资源，也不会启动游戏或启动器。
