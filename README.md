# 明日方舟鼠标替换补丁

让《明日方舟》PC 版使用 Windows 系统指针，不修改游戏文件。

## 使用

1. 运行 `ArkCursorPatch.exe`。
2. 选择“启动系统指针模式”并保持工具运行。
3. 正常启动游戏；游戏已经运行时也可直接生效。

如果自动定位失败，可在工具中手动设置游戏目录。

## 安全

- 工具会请求管理员权限，在运行期间关闭游戏的自绘指针并重置为 Windows 系统箭头。
- 不修改游戏文件、不注入 DLL；只修改当前游戏进程内存，停止模式时还原，重启游戏也会完全失效。
- 游戏更新后若无法唯一识别目标代码，工具会拒绝修改。

## 声明

> 本工具仅供交流与学习。使用前请自行评估并承担修改游戏进程可能产生的风险。
